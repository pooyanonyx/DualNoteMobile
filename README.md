# DualNote برای تبلت و گوشی اندروید

نسخهٔ وب (قابل نصب مثل یک برنامه، PWA) از DualNote: PDF و دفترچه کنار هم (روی تبلت) یا با تب (روی گوشی).
همهٔ امکانات نسخهٔ ویندوز را دارد: قلم، ماژیک، هایلایت متن، پاک‌کن، متن، **نوت چسبان**، خط/فلش/مستطیل/دایره،
انتخاب و **تغییر اندازه با دایره‌ها**، چسباندن عکس (Ctrl+V یا دکمهٔ Paste یا انتخاب عکس)، رنگ‌های زیاد + رنگ دلخواه RGB/HEX،
شفافیت/روشنی/ضخامت، undo/redo، چیدمان‌ها (PDF | دفترچه، دفترچه | PDF، دفترچه | دفترچه، PDF | PDF) با دکمهٔ Switch،
ذخیرهٔ **کل کار در یک فایل** (`.dnws`) و ذخیرهٔ خودکار روی دستگاه.

فایل‌ها با نسخهٔ ویندوز **قابل تبادل‌اند**: فایل workspace (`.dnws`) و دفترچه (`.dnote`) در هر دو برنامه باز می‌شوند.

## ساده‌ترین راه برای نصب روی اندروید (بدون Android Studio)

برنامه فقط چند فایل ثابت است (پوشهٔ `www`). باید روی یک آدرس **HTTPS** قرار بگیرد تا اندروید اجازهٔ «نصب» و حالت آفلاین بدهد.

1. در کامپیوتر به <https://app.netlify.com/drop> برو (ثبت‌نام لازم نیست یا با ایمیل ساده).
2. پوشهٔ **`www`** را (خود پوشه، نه zip) روی صفحه بکش و رها کن. بعد از چند ثانیه یک آدرس مثل `https://something.netlify.app` می‌دهد.
3. آن آدرس را در **Chrome گوشی/تبلت** باز کن.
4. منوی Chrome (سه نقطه) ← **Install app** (یا **Add to Home screen**) ← Install.
5. حالا آیکن DualNote روی صفحهٔ اصلی است. بار اول با اینترنت باز کن؛ بعد از آن **بدون اینترنت** هم کار می‌کند.

جایگزین‌ها به‌جای Netlify: GitHub Pages، Cloudflare Pages (همان پوشهٔ `www` را آپلود کن).

**به‌روزرسانی:** فایل‌ها را عوض کن، در `www/sw.js` عدد `CACHE = "dualnote-v1"` را بالا ببر (v2، v3…)، دوباره آپلود کن.
اگر فایل اضافه/حذف کردی اول `python tools/gen_precache.py` را اجرا کن.

## راه دوم: بدون آپلود، با کابل USB (برای آزمایش)

1. روی گوشی «Developer options» و «USB debugging» را روشن کن و با کابل به کامپیوتر وصل کن.
2. روی کامپیوتر (با نصب بودن `adb`) در پوشهٔ پروژه:
   ```
   python -m http.server 8080 --directory www
   adb reverse tcp:8080 tcp:8080
   ```
3. در Chrome گوشی برو به `http://localhost:8080` (آدرس localhost به‌عنوان «امن» حساب می‌شود، پس نصب و آفلاین کار می‌کند).

(باز کردن مستقیم با آدرس IP شبکه، مثل `http://192.168.x.x:8080`، **امن حساب نمی‌شود**: نصب، آفلاین و دکمهٔ Paste کار نمی‌کنند.)

## راه سوم (اختیاری): ساخت فایل APK

با Capacitor. نیاز: Node.js و Android Studio.
```
npm install
npm run cap:add        # یک بار
npm run cap:sync       # بعد از هر تغییر در www
npm run cap:open       # Android Studio باز می‌شود؛ Build > Build APK
```
این مسیر را **من تست نکرده‌ام** (در محیط من Android Studio نیست). در نسخهٔ APK دکمه‌های ذخیره از «Share» اندروید استفاده می‌کنند.

## استفادهٔ لمسی

- **یک انگشت:** با ابزار انتخاب‌شده می‌کشد. با ابزار Select روی فضای خالی بکش تا صفحه جابه‌جا شود.
- **دو انگشت:** جابه‌جایی و بزرگ/کوچک کردن (pinch). همیشه کار می‌کند.
- **قلم/استایلوس:** وقتی با قلم می‌کشی، لمس انگشت (کف دست) تا حدود ۱ ثانیه نادیده گرفته می‌شود.
- **متن و نوت:** با ابزار Text یا Note روی صفحه لمس کن، بنویس، بیرون لمس کن تا تمام شود. دابل‌تپ روی متن/نوت (با Select) ویرایش می‌کند.
- **تغییر اندازه:** با Select آیتم را انتخاب کن؛ دایره‌های کنارش را بکش. عکس و متن متناسب بزرگ می‌شوند.
- **عکس:** دکمهٔ Paste (عکس/متن کلیپ‌بورد) یا Image (گالری/دوربین) یا Ctrl+V (کیبورد).
- **جای بیشتر:** دکمهٔ «Toolbars» بالای هر پنل نوارها را پنهان می‌کند.

## ذخیره

- **Save workspace:** کل کار (PDF اصلی، حاشیه‌نویسی‌ها، دفترچه‌ها، تنظیمات) در یک فایل `.dnws` (دانلود می‌شود).
- **Save PDF** (در پنل PDF): یک PDF جدید با حاشیه‌نویسی. حاشیه‌نویسی‌ها به‌صورت تصویر روی صفحه می‌نشینند و PDF اصلی + دادهٔ قابل‌ویرایش داخلش ذخیره می‌شود؛ پس دوباره در همین برنامه (و برنامهٔ ویندوز) قابل ویرایش باز می‌شود.
- کار شما به‌طور خودکار روی خود دستگاه هم نگهداری می‌شود و بعد از بستن/باز کردن برنامه برمی‌گردد.

## تست‌ها (در مرورگر واقعی)

```
npm install
npx playwright install chromium
npm test
```
شامل: مقایسهٔ منطق با مدل پایتونِ برنامهٔ ویندوز روی ~۳۰۰۰ مورد تصادفی، و ۱۵۶ بررسی end-to-end در Chromium (رسم، همهٔ ابزارها، رنگ و برس،
عکس و چسباندن، خروجی PDF حتی صفحه‌های چرخیده، workspace، خواندن/نوشتن فایل‌ها با کد پایتونِ برنامهٔ ویندوز، چیدمان‌ها، ذخیرهٔ خودکار،
آفلاین، چیدمان گوشی/تبلت، لمس دو انگشتی، رد کردن کف دست).

## محدودیت‌های شناخته‌شده

- همهٔ تست‌ها در **Chromium دسکتاپ** (با شبیه‌سازی لمس/قلم و اندازهٔ گوشی/تبلت) انجام شده، نه روی یک گوشی یا تبلت واقعی. حس لمس، کیبورد فارسی روی صفحه، مجوز کلیپ‌بورد و رفتار دانلود در Chrome اندروید ممکن است فرق کند.
- PDF خروجی: حاشیه‌نویسی‌ها تصویر (با وضوح ~۲۱۶ dpi) هستند، نه وکتور (نسخهٔ ویندوز وکتور می‌نویسد).
- هایلایت متن از روی جای تقریبی کلمات در PDF ساخته می‌شود؛ روی PDFهای ساده تست شده.
- PDFهای رمزدار پشتیبانی نمی‌شوند. PDFهای خیلی بزرگ روی گوشی‌های ضعیف تست نشده‌اند.
- PDF حاشیه‌نویسی‌شده‌ای که **این** برنامه می‌سازد را با خود برنامهٔ ویندوز آزمایش نکرده‌ام (فایل‌های `.dnws` و `.dnote` را آزمایش کرده‌ام).
- رابط فقط انگلیسی است. iOS/Safari تست نشده.
